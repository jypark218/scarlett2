# 데라디 가게 비주얼 디렉팅 TF

- 가게: 데이즈라이크디스 (Days Like This, 줄여서 DLT·데라디)
- 업종: 에스프레소 바 기반 카페
- 위치 / 매장 규모: 구로디지털단지역, 직장인 상권 / 약 8평
- 주요 고객 (자주 오는 순): 30~40대 남성 위주 → 가족·애견인 → 1인 손님
- 지금 필요한 작업
  - 2026년: 로고, 컵 심볼, 각대봉투·포장 제품 디자인 리뉴얼 (진행 중)
  - 2027년 예정: 내부 바 벽 포스터 레이아웃 변경, 소모품 디자인 전반 변경
- 유지해야 할 것: 에스프레소 바 메뉴, 호스피탈리티
- 바꾸는 방향: 핸드 드로잉 느낌으로 변경 중
- 예산 범위 / 일정: 규칙 없음(확인 필요). 디자인 1건당 약 2주 의견만 나온 상태

  - 인스타그램: https://www.instagram.com/dayslikethis_espressobar/
