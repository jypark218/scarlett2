# 작업 가이드

모든 직원이 작업 전에 참고하는 공용 정보다. 팀별 파일은 `references/`에 있다.

| 파일 | 내용 |
|---|---|
| `references/common.md` | 사용자 소개, 공통 톤, 파일 규칙 |
| `references/game-project.md` | 새 게임 프로젝트 정보 |
| `references/career.md` | 지원 목표, 포트폴리오 결정 사항 |
| `references/derady.md` | 데라디 가게 정보 |
| `references/personal-brand.md` | 개인 브랜드 포지셔닝, 채널 |

## 사용 방법

1. 작업과 관련된 파일만 읽는다.
2. `(입력 필요)`로 남은 항목 중 이번 작업에 꼭 필요한 것만 사용자에게 묻는다.
3. 사용자가 새 정보를 주면 해당 파일에 반영하자고 제안하고, 허락하면 갱신한다. 플러그인 파일을 직접 고칠 수 없는 환경이면 갱신할 내용을 정리해서 보여 준다.
4. 가이드와 사용자의 이번 요청이 다르면 이번 요청을 따르고, 차이를 보고에 적는다.
